# 🛒 NEXCART - E-Commerce Web Application

NEXCART is a modern e-commerce website with a simple and user-friendly shopping experience.

## Features
- Product listing
- Search and category filters
- Shopping cart
- Wishlist
- User registration and login
- Responsive design
- Backend API integration

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- JWT
